Theseus Maze Simulator

Runs the robot's exploration planner on RCJ Rescue Maze fields with black, blue and silver tiles and ramps. The realism setting adds the faults a real run has (misread walls, stalls, wheel slip, miscounted ramps, missed black tiles, the 8-minute clock) and sends each one through the same recovery code as Main/.
